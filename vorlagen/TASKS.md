# Aufgaben

Eine Aufgabe pro Durchlauf, von oben nach unten. Abhaken (`- [x]`) nur, wenn die Prüfung grün ist und neue Prüfungen das Kriterium belegen.
Klein schneiden: Jede Aufgabe muss in einem Durchlauf (höchstens 45 Minuten) schaffbar und automatisch prüfbar sein.

- [ ] 1. Beispiel: Funktion `summe(liste)` in `src/rechnen.py`. Fertig, wenn Tests für leere Liste, eine Zahl und negative Zahlen bestehen.
- [ ] 2. Beispiel: `mittelwert(liste)` auf Basis von `summe`. Fertig, wenn Tests für gerade, ungerade und leere Listen (Fehler `ValueError`) bestehen.
